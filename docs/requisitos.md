# Baseline de requisitos — AE III

Renumerados a partir da AE II, que usava R01 e RF2–RF5 com códigos mistos.

## Requisitos funcionais

| Código | Descrição |
|---|---|
| RF01 | Disponibilizar módulos educacionais sobre cibersegurança, abordando phishing, senhas seguras, malware e fraudes on-line. |
| RF02 | Apresentar casos reais de ataques cibernéticos, como phishing e engenharia social, para demonstrar a forma de agir dos criminosos. |
| RF03 | Aplicar quizzes e testes interativos para avaliar o conhecimento adquirido pelo aluno. |
| RF04 | Executar simulações práticas, como a análise de mensagens e de e-mails suspeitos. |
| RF05 | Sugerir medidas preventivas de acordo com os hábitos de navegação relatados pelo aluno. |
| RF06 | Fornecer dicas e orientações práticas de segurança, tanto para o uso pessoal quanto para o ambiente escolar. |
| RF07 | Registrar o desempenho das turmas nos quizzes e nas simulações e gerar relatório comparativo entre elas. |
| RF08 | Controlar a versão do conteúdo educacional aplicado em cada turma, mantendo o histórico de alterações. |

## Requisitos não funcionais

| Código | Descrição |
|---|---|
| RNF01 | Utilizar linguagem acessível ao público leigo, observando os princípios do Desenho Universal. |
| RNF02 | Executar o material nos computadores e projetores já disponíveis nas escolas, sem exigir instalação adicional. |
| RNF03 | Disponibilizar todo o material em formato aberto e gratuito, permitindo o reuso pelas escolas. |
| RNF04 | Armazenar os dados de desempenho de forma anônima, sem identificação individual dos alunos. |
| RNF05 | Manter os artefatos versionados em repositório público, com histórico de alterações rastreável. |
| RNF06 | Manter a duração de cada aula em, no máximo, cinquenta minutos. |

## Rastreabilidade com a AE II

| RF2 | RF02 |
| RF3 | RF03 |
| RF4 | RF05 |
| RF5 | RF06 |
